# JobTrackly 🚀

JobTrackly is a web-based Job Application Tracking System built with Django that helps job seekers organize applications, track interview stages, and manage their overall job search efficiently.

## 🌟 Features

- User Authentication & Authorization
- Job Application Management
- Application Status Tracking
- Interview Tracking
- Company Information Management
- Dashboard Overview
- Responsive User Interface
- Secure Data Storage

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
  
### Backend
- Python
- Django
